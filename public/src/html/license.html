DNI Terminal — Licensing & Origin

The current application is a Dreadnought Imperium DNI terminal with local DNI archive records. It does not retrieve or republish the external fictional database content used by an earlier version.

Historical provenance

Historical upstream attribution and licensing details are preserved only in the repository-level UPSTREAM_SOURCE.md. That provenance record is intentionally kept separate from the current runtime and branding.

Current runtime

DNI branding, interface copy, local record definitions, responsive behavior, and the DNI logo are maintained as committed project source.
