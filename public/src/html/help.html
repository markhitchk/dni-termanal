DNI Terminal Help

HELP
Displays available terminal commands.
ACCESS <number>
Opens a local DNI archive record. Example: ACCESS 173.
LIST
Lists the authored DNI archive records bundled with the terminal.
TERMINAL
Switches to DNI Terminal.
IMPERIUM
Switches to Dreadnought Imperium.
DIRECT
Switches to DNI DIRECT ACCESS TERMINAL.
COMMUNICATIONS
Switches to DNI Communications.
SERVICES
Switches to DNI Services.
DASHBOARD
Switches to DNI Dashboard.
ABOUT
Displays DNI Terminal build information.
CLEAR
Clears and restarts the terminal display.
