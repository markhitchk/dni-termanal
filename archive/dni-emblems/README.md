# Retired DNI emblem assets

The old Army emblem is retained here for archival purposes only. **These files must not be published as active emblems.**

- `retired-army/gallery-preview.png` is the previous public gallery preview.
- `retired-army/cdn-original.png` is the previous full-resolution CDN source.

Both files are intentionally stored outside the `public/` Apache document root. The public gallery now shows an unavailable state for the **Imperial Marine Corps**, and Apache deny rules prevent requests to the former paths even if obsolete copies remain on the server.

To introduce a new Marine Corps emblem, use new Marine-specific filenames and public paths; do not restore the old Army image URLs.
